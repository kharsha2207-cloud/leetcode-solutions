### Approach

I used a nested loop to check every possible pair of elements in the array. If the sum of two elements equals the target, their indices are returned.

### Complexity

- Time: O(n²)
- Space: O(1)

### Notes

I tested a typical case and an edge case with duplicate values. The solution should not use the same element twice.
